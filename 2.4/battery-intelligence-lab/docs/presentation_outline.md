# 발표 구성안 (12장) — NASA 데이터 기반 배터리 수명 예측과 실차 적용

모든 그래프는 프로젝트에서 실제 데이터로 생성된 파일이다(경로는 `battery-intelligence-lab/` 기준). 수치는 `docs/experiment_report.md`, `docs/final_validation_report.md`와 각 결과 CSV에서 가져왔다. 발표 비중은 NASA 모델 개발 7장(1~8), 실차 확장 3장(9~11), 결론 1장이다.

---

### 1. 연구 배경
- **핵심 설명:** 전기차 배터리는 사용할수록 용량이 줄고, 언제 교체해야 하는지(SOH·RUL) 예측해야 한다. 용량을 직접 재려면 완전 방전 시험이 필요해 실사용 중에는 측정하기 어렵다.
- **그래프:** `results/nasa/figures/rul_capacity_eol.png` (Cycle에 따른 방전 용량 감소와 EOL 1.4 Ah)
- **발표 내용:** 그림처럼 같은 시험 조건에서도 셀마다 수명이 다르다(B0005 125회, B0006 109회, B0018 97회에 EOL 도달, B0007은 168회까지 미도달). 측정하기 쉬운 충전 데이터로 용량을 추정할 수 있다면 실용적이다.

### 2. 연구 목표
- **핵심 설명:**
  1. NASA 데이터로 SOH 회귀 모델 5종을 만들고 비교한다.
  2. 정답 누출이 없는 검증으로 모델을 고른다.
  3. 미래 SOH·RUL을 예측한다.
  4. NASA 모델을 실제 전기차에 적용해 본다.
- **그래프:** 없음 (목표 4개를 텍스트로)
- **발표 내용:** 중심은 1~3번이고, 4번은 "실험실 모델이 실차에서도 통하는가"를 확인하는 확장 실험이다.

### 3. NASA 배터리 데이터
- **핵심 설명:** NASA PCoE 공개 데이터. B0005·B0006·B0007·B0018 네 셀, 정격 2.0 Ah, 상온 24 ℃. 충전(1.5 A CC-CV), 2 A 방전, 임피던스 측정을 반복했다. 방전 Cycle은 총 636회다.
- **그래프:** `results/ev10/figures/ev10_vs_nasa_charge_curves.png`의 왼쪽 패널 (NASA 충전 곡선의 노화 전후 변화)
- **발표 내용:** 노화가 진행될수록 같은 전압에 더 빨리 도달한다. 이 충전 곡선의 변화가 모델 입력의 핵심이다. 파일을 직접 열어 README와 다른 필드명 2곳을 찾아 기록했다.

### 4. 사용한 AI 회귀 모델
- **핵심 설명:** Linear Regression, Random Forest, SVR(RBF), XGBoost, Stacking(앞 4개 + Ridge). 하이퍼파라미터는 미리 고정했다.
- **그래프:** 없음 (모델별 특징 표)
- **발표 내용:**
  - 선형 모델은 학습 범위 밖으로 외삽할 수 있다. 트리·커널 모델은 학습 범위 밖에서 포화된다.
  - Stacking은 내부 학습이 같은 배터리의 미래를 보지 않도록 시간·배터리 단위로 나눠 학습한다(감사에서 발견해 수정).

### 5. 데이터 전처리 및 특징 추출
- **핵심 설명:**
  - 방전 k의 입력은 **방전 k가 시작되기 전**의 정보만 쓴다: 직전 충전 곡선(CC·CV 시간, 전압, 온도, dQ/dV), 직전 임피던스(Re, Rct), Cycle 번호.
  - 결측·이상 처리 규칙과 처리 건수를 기록했다(불완전 충전 3회/셀, 임피던스 없는 초기 19회 등).
- **그래프:** 없음 (특징 그룹 표 + "현재 방전 곡선은 쓰지 않는다"는 이유)
- **발표 내용:** 방전 곡선 길이 × 2 A가 곧 용량이므로, 이를 입력에 넣으면 정답을 그대로 알려 주는 셈이다. 미래 데이터를 지워도 특징이 같은지 자동 테스트로 확인했다.

### 6. NASA SOH 예측 성능
- **핵심 설명:**
  - 시간순 분할에서 학습 데이터로 선정한 **Linear Regression MAE 0.0239**(R² 0.76).
  - 미학습 배터리(LOBO)에서 선정 모델 평균 **0.0374**.
  - Random split은 0.004~0.010으로 과대평가된다.
- **그래프:** `results/nasa/figures/exp_A_split_comparison.png`, `results/nasa/figures/exp_C_lobo_soh_actual_vs_pred.png`
- **발표 내용:**
  - 평가 방식만 바꿔도 1위 모델이 바뀐다. SVR은 Random split 1위에서 시간순 꼴찌가 된다.
  - 테스트 결과로 모델을 고르면 LOBO가 0.0242로 보이지만, 학습 데이터로 고르면 0.0374다.
  - 직전 SOH를 그대로 쓰는 기준선(0.0046)은 직전 용량 실측이 필요해, 실사용 조건과 다르다.

### 7. Small Data 및 Stacking
- **핵심 설명:**
  - 배터리당 처음 50회 이하만 학습하면 선정 모델의 R²가 모두 음수다.
  - Stacking은 시간순에서 0.0143(사후 최저)이지만, 미학습 배터리에서는 0.0408로 단일 모델보다 나쁘다.
- **그래프:** `results/nasa/figures/exp_B_small_data.png`
- **발표 내용:**
  - 적은 데이터로 먼 미래를 예측하면 결과가 크게 흔들린다(N=50에서 0.014였다가 N=70에서 0.042).
  - Stacking의 내부 학습이 미래 Cycle을 보던 문제를 고친 뒤, 장점과 한계가 함께 드러났다.

### 8. 미래 SOH·RUL 예측
- **핵심 설명:**
  - 미래 +10/+20 Cycle에서 선정 모델(XGB/LR)은 0.024~0.040이고, 단순 선형 외삽은 0.009~0.029다.
  - RUL(1.4 Ah)은 선정 방법 기준 B0006 14.7, B0018 9.9 Cycle 오차이고, B0005는 용량 회복 구간에서 실패(123.9)했다.
  - B0007은 EOL 미관측이라 정답을 만들지 않았다.
- **그래프:** `results/nasa/figures/future_soh_lobo.png`, `results/nasa/figures/rul_prediction.png`
- **발표 내용:**
  - 복잡한 모델이 항상 이기지는 않는다.
  - RUL 실패 건수와 성공률도 함께 보고했다(B0005 최근 30점 외삽: 106회 중 6회 교차 실패).
  - 일부 모델은 음수 RUL을 예측했다.

### 9. NASA 모델의 실제 전기차 적용
- **핵심 설명:**
  - 실차 10대(EV10, 차량당 SOH 정답 1개)에는 온도·임피던스·Cycle 정보가 없다.
  - 그래서 공통으로 존재하는 충전 곡선 특징(전압창 충전량 / 정격용량)만으로 NASA 모델을 다시 학습해 적용했다. 차량 5는 라벨 불일치로 제외해 9대를 평가했다.
- **그래프:** `results/transfer/figures/transfer_charge_curves.png`
- **발표 내용:** 셀(2 Ah, 0.75 C, 단자전압)과 팩(100~234 Ah, 약 0.3 C, 셀 평균전압)은 측정 조건이 다르다. 모델 선택은 NASA 데이터로만 했고, 실차 정답은 최종 평가에만 썼다.

### 10. 정규화 전후 성능 비교
- **핵심 설명:**
  - 정규화 전(A0/XGBoost) **0.2187** → NASA로 선정한 정규화 후(B3/Stacking) **0.2451**. 차이의 95 % CI −0.016~+0.065로 개선되지 않았다.
  - 저항 보정은 0.31~0.32이고, NASA 평균값 기준선은 0.1388이다.
- **그래프:** `results/transfer/figures/transfer_metrics_comparison.png`, `results/transfer/figures/transfer_vehicle_predictions.png`
- **발표 내용:**
  - 9대 모두 과소 예측했다.
  - 사후 탐색에서 MAE 0.07~0.11인 방법도 차량 순서는 맞히지 못했다. 그래서 성능으로 주장하지 않는다.

### 11. 실차 확장의 한계 및 개선 방향
- **핵심 설명:**
  - 같은 좌표(관측 충전 진행률)로 비교하면, NASA는 충전 0~37 %에서, 실차는 61~87 %에서 3.9~4.0 V에 도달한다.
  - 저항 보정은 측정 방식(전류 방향 전환, 시간 척도)이 달라 근사일 뿐이다.
  - 장기 실차(EV20)에서는 추세 방향은 맞지만 수준과 기울기가 다르고(0.67 대 0.85, 기울기 약 1/8), 실측 SOH가 없다.
- **그래프:** `results/final_validation/figures/voltage_vs_observed_progress.png`, `results/transfer/ev20/figures/ev20_nasa_pred_vs_capacity.png`
- **발표 내용:**
  - 단위 정규화로는 화학계와 셀 설계의 차이를 없앨 수 없다.
  - 개선하려면 실차와 같은 화학계·충전 조건의 셀 데이터와, 충전 기록과 독립적으로 측정한 팩 용량 정답이 필요하다.

### 12. 최종 결론
- **핵심 설명:**
  1. NASA 데이터로 SOH 오차 약 2.4 %p(시간순)~3.7 %p(미학습 배터리)의 예측 모델을 개발했다.
  2. 검증 방식이 결론을 좌우하며, 학습 데이터만으로 모델을 선정했다.
  3. NASA 모델을 실차에 그대로 쓰면 오차가 약 0.22이고, 정규화로 개선되지 않은 원인을 데이터로 확인했다.
- **그래프:** 없음 (결론 3줄 + 향후 과제)
- **발표 내용:** 이 과제의 성과는 "정확도를 억지로 높인 것"이 아니라, 믿을 수 있는 방식으로 모델을 만들고 실차 적용의 한계를 수치로 보인 것이다. 향후 과제는 같은 화학계 셀 데이터 확보, 독립적인 팩 용량 라벨, 조건이 다양한 학습 데이터다.
