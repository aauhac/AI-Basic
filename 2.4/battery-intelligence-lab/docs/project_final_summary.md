# 프로젝트 최종 요약 — NASA 데이터 기반 리튬이온 배터리 수명(SOH·RUL) 예측

AI기초프로젝트 레벨 2 · 2026-10

## 1. 한 줄 요약
NASA 배터리 노화 데이터로 SOH(건강 상태)와 RUL(잔여 수명)을 예측하는 회귀 모델 5종을 만들어, 정답 누출을 막는 검증 방식으로 비교했다. 같은 모델을 실제 전기차 데이터에도 적용해 보았고, 실차에서는 정확도가 크게 떨어진다는 것과 그 원인을 데이터로 확인했다.

## 2. 실제로 만든 AI 모델
| 모델 | 역할 |
|---|---|
| Linear Regression | 기준 모델. 해석이 쉽고, 학습 데이터 밖으로의 외삽(추세 연장)에 비교적 강함 |
| Random Forest | 비선형 관계. 학습 범위 밖 예측에 약함 |
| SVR (RBF 커널) | 비선형 관계. 학습 범위 밖에서 예측값이 한 값에 머무름(포화) |
| XGBoost | 부스팅 트리. 미래 SOH 예측에서 자주 선정됨 |
| Stacking | 위 4개 모델의 예측을 다시 결합. 시간 순서·배터리 단위로 겹치지 않게 학습 |

- **입력:** 방전 직전 충전 곡선에서 뽑은 특징(충전 시간, 전압, 온도, dQ/dV)과 임피던스(Re, Rct), Cycle 번호. 과거 용량 이력은 비교 실험에서만 썼다.
- **정답:** SOH = 해당 Cycle의 방전 용량 / 첫 방전 용량.
- **데이터:** NASA B0005·B0006·B0007·B0018 네 셀, 방전 636회.

## 3. NASA SOH 예측 결과
| 평가 방식 | 의미 | 결과 (MAE, SOH 단위) |
|---|---|---|
| 시간순 분할 (앞 70 % 학습 → 뒤 30 % 예측) | 같은 배터리의 미래 Cycle | 선정 모델 **Linear Regression 0.0239** (R² 0.76) |
| 미학습 배터리 (LOBO) | 처음 보는 배터리 | 선정 모델 평균 **0.0374** |
| Random split (참고) | 인접 Cycle이 학습·평가에 섞임 | 0.004~0.010 → **과대평가**로 판단해 성능 주장에서 제외 |
| 직전 Cycle SOH를 그대로 쓰는 기준선 | 직전 용량을 실측해야 가능 | 0.0046 |

- **SOH 0.0239의 의미:** SOH 1.0을 100 %로 볼 때 평균 약 2.4 %p의 오차다.
- **Small Data:** 배터리당 처음 50회 이하만 학습하면 모든 선정 모델의 R²가 음수다. 적은 데이터로 먼 미래를 예측하기는 어렵다.
- **Stacking:** 시간순에서는 단일 모델보다 낫지만(0.0143, 사후 비교), 미학습 배터리에서는 오히려 나쁘다(0.0408).

## 4. 가장 적합한 모델을 고른 방법
1. 하이퍼파라미터는 미리 고정했고, 테스트 데이터로 튜닝하지 않았다.
2. **학습 데이터 안에서만** 검증해 모델을 골랐다. 시간순은 학습 구간의 마지막 20 %, 미학습 배터리는 학습 배터리끼리 서로 빼 보는 검증을 썼다.
3. 고른 모델의 테스트 성능만 결과로 보고했다. 모든 모델의 테스트 성능은 참고표로만 남겼다.
4. 감사 과정에서 Stacking의 내부 학습이 같은 배터리의 미래 Cycle을 보던 문제(42~60 %)를 발견해 고치고 다시 실험했다.

**결론:** NASA 현재 SOH 추정에는 **Linear Regression**이 학습 데이터 기준으로 선정되었다. 미래 SOH 예측에서는 주로 **XGBoost**가 선정되었다.

## 5. 미래 SOH·RUL 예측
- **미래 10·20 Cycle SOH:** 선정 모델(XGB/LR)은 0.024~0.040이고, 최근 20점 선형 외삽은 0.009~0.029이다. 단순 외삽이 같거나 더 정확했다.
- **RUL** (1.4 Ah 도달까지 남은 Cycle):
  - 실제 EOL은 B0005 125회, B0006 109회, B0018 97회다.
  - 선정 방법의 오차는 B0006 14.7, B0018 9.9 Cycle이다. B0005는 용량이 일시적으로 회복되는 현상 때문에 123.9 Cycle로 실패했다.
  - B0007은 1.4 Ah에 도달하지 않아 정답 RUL을 만들지 않았다.

## 6. 실제 전기차 적용 방법
1. 실차(EV10, 10대 팩)에는 온도·임피던스·Cycle 번호가 없다. 그래서 NASA 모델을 **실차에도 있는 충전 곡선 특징**(전압창 충전량 / 정격용량)만으로 다시 학습했다.
2. 정규화 방법(구간별 충전량, 구간 비율, 저항 보정)은 **NASA 데이터만으로** 선택했고, 실차 정답은 최종 평가에만 썼다.
3. 실차 평가는 라벨 문제가 있는 차량 5를 뺀 9대로 했다.

## 7. 정규화 전후 결과 (EV10, 9대)
| 방법 | MAE |
|---|---:|
| 정규화 전 (기존 공통 특징 + XGBoost) | 0.2187 |
| **정규화 후 (NASA만으로 선정: 구간 충전량+비율 + Stacking)** | **0.2451** |
| 저항(IR) 보정 (참고) | 0.31~0.32 |
| 기준선: NASA 평균 SOH를 그대로 예측 | 0.1388 |
| (사후 탐색, 성능 주장 아님) 구간 비율 + SVR | 0.1091 |

- 정규화로 **개선되지 않았다.** 모든 차량을 0.6~0.8로 과소 예측하며, 실제 SOH는 0.79~1.02다.
- 사후 탐색에서 MAE가 낮게 나온 방법도 차량 간 순서를 맞히지 못했다(순위 상관 ≤ 0.05).

## 8. 원인 (데이터로 확인)
- **같은 전압이 다른 충전 위치를 가리킨다.** 동일한 좌표(관측 충전 진행률)로 비교하면, NASA 셀은 충전 초반(0~37 %)에 3.9~4.0 V에 도달하고 실차 팩은 후반(60~87 %)에 도달한다.
- **NASA 조건이 한 가지뿐이다.** 충전 속도 0.75 C, 온도 24 ℃ 하나라서, 실차의 다른 충전 조건을 배울 수 없다.
- **저항 보정에 한계가 있다.** 두 데이터의 저항 측정 방식과 시간 척도가 달라, 보정은 근사일 뿐이며 차이를 메우지 못한다.
- **실차 정답이 적고, 같은 충전 기록에서 계산된다.** 라벨이 10개뿐이라 보정 효과를 통계적으로 확인할 수 없다.

## 9. 장기 실차(EV20) 확장
- 20대·28개월 충전 기록에 NASA 모델을 적용하면 감소 방향은 맞다(20대 모두 같은 방향).
- 그러나 예측 수준(0.67)과 감소 속도(약 1/8)가 SOC 기반 추정 용량(0.85)과 크게 다르다.
- 실측 SOH가 없어 정확도를 평가할 수 없으므로, SOH 추정값으로는 쓸 수 없다고 판정했다.

## 10. 최종 결론
1. NASA 데이터에서는 엄격한 검증 아래 **SOH 오차 약 2.4 %p(시간순)~3.7 %p(미학습 배터리)** 의 예측 모델을 만들었다.
2. 검증 방식에 따라 결론이 크게 달라진다. Random split은 성능을 과대평가하고, 테스트로 모델을 고르면 성능이 부풀려진다.
3. NASA 단일 셀 모델을 실차 팩에 그대로 쓰면 오차가 약 0.22이고, 이번 정규화로는 개선되지 않았다. 원인은 셀과 팩의 충전 곡선(전압–충전 위치) 차이와 학습 조건의 단일성이다.
4. 실차로 확장하려면 실차와 같은 화학계·충전 조건의 셀 데이터와, 독립적으로 측정한 팩 용량 정답이 필요하다.

## 11. 발표에서 강조할 핵심
- **중심은 NASA 기반 수명 예측 모델 개발이다.** 5개 모델 비교, 정답 누출 방지 검증, 모델 선정 기준.
- "점수가 가장 좋은 모델"이 아니라 **학습 데이터만으로 고른 모델**을 결과로 제시했다.
- 실차 적용은 "실패를 숨기지 않은 확장 실험"이다. 개선되지 않은 원인을 데이터로 보여 주는 것이 결과다.
