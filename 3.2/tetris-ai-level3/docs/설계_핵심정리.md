# 인간–AI 대전 테트리스 설계 핵심 정리 (최종본, 2026-11-16)

## 1. 문제 분석 → 설계 연결

| 과제 요구 | 핵심 문제 | 설계 결정 |
|---|---|---|
| 4개 모드 + 승패 | 모드마다 플레이어 수·공격 여부·승리 조건이 다름 | `engine.Match` 한 곳에서 모드 규칙 처리, GUI는 결과만 표시 |
| 공격 시스템 | 고정·줄 제거·공격·수신의 순서가 틀리면 오판정 | `Player.lock()` 8단계 고정 순서 (고정 → active 해제 → 줄 제거·점수 → Combo/B2B/T-Spin → 공격 → 상쇄 → 방해 줄 삽입 → Top-out → 다음 블록) |
| 현재+다음 블록 AI | 경우의 수(약 34 × 34) 평가를 빠르게 | 비트마스크 보드, 열 높이 낙하 계산, 이동 전 평가 1회 계산, 결과 캐시 |
| 3단계 난이도 | 이름만 다른 난이도 방지 | 평가 항목 수(3 → 7)와 탐색 깊이(1 → 2단계)를 바꾸고 실제 대전으로 차이 측정 |
| 독립 처리·동기화 | AI 계산이 입력·낙하·그리기를 막음 | `AIWorker` 작업 스레드 + 보드 복사본 + `queue.Queue` + 토큰 검사, Tk 위젯은 메인 스레드만 |
| 기록 저장 | 파일 손상·중단 경기 처리 | 원자적 저장(임시 파일 + `os.replace`), 손상 시 기본값, 중단 경기는 `aborted` |

## 2. 고려한 대안과 선택 이유

- **AI 연산 분리:** ① 메인 스레드에서 계산(원본, 최대 6.9초 정지) ② 별도 프로세스(GIL 없음, 하지만 Windows에서 시작이 느리고 직렬화·종료 처리가 복잡) ③ **작업 스레드 + 최적화(채택)** — 최적화 후 어려움 1회 탐색이 최대 약 190 ms라 GIL 영향이 작고 구조가 단순함.
- **최적화 방식:** 탐색 후보를 줄이는 빔 탐색은 결과가 달라질 수 있어 채택하지 않음. **같은 결과를 더 빨리 계산하는 방식**만 쓰고, 원본과 300/300 동일함을 확인.
- **AI 배치 실행:** 순간 이동(원본) 대신 **실제 회전·이동 동작을 한 단계씩 실행**해 인간과 같은 규칙을 따르게 함.
- **퍼즐 생성:** 무작위 보드에서 해답을 찾는 방식은 성공률이 낮음 → **완성된 T-Spin 구조에서 블록을 제거하는 역방향 구성 + BFS 검증(생성-검증)**을 채택. 시드별 1회 시도로 생성됨(시드 150개 측정).

## 3. AI 평가함수 (보통·어려움, 도우미와 동일)

평가 = 110 × (제거 줄 수)² + 150 × T-Spin 가점 − 14 × 최대 높이 변화 − 64 × 구멍 변화 − 6.5 × 평탄도 변화 − 3.4 × 전체 높이 변화 + 14 × T-Spin 후보 변화
어려움 = 위 점수 + 0.65 × (다음 블록의 최선 배치 점수)
쉬움 = 줄 제거 − 14 × 최대 높이 변화 − 0.35 × 64 × 구멍 변화

도우미의 각 수치는 **게임 점수가 아니라 AI 내부 휴리스틱**이며, 같은 함수로 계산한 추천 위치 점수와 비교할 수 있습니다.

## 4. 퍼즐 생성·검증

1. 무작위 열·방향(좌우 대칭)·바닥 방해 줄(0~2줄)로 T-Spin Double 구조 생성
2. 난이도별로 제거: 보통 = 지붕(I 블록 자리), 어려움 = 지붕 + 2×2 빈칸(O 블록 자리)
3. 준비 블록마다 BFS(상태: x, y, 회전, 마지막 동작이 회전인지 / 동작: ←, →, ↓, ↻, ↺)로 실제 도달 가능한지 확인
4. 최종 T가 실제 T-Spin으로 목표 줄 수를 지울 수 있는지 확인
5. 필요성 검사: 초기 보드에서는 불가능, 어려움은 I만·O만 놓아도 불가능
6. 최대 60회 시도, 실패 시 `PuzzleGenerationError` (GUI는 안내만 표시)

## 5. 검증 요약

- 자동 테스트 100개 통과 (원본 23 + 신규 77, 실제 Tk 창 GUI 테스트 16개 포함)
- 버그 6건을 원본/수정본에서 같은 시나리오로 재현·확인 (`verification/bugfix_summary.md`)
- 성능: 어려움 탐색 평균 859 → 49.5 ms, GUI 최대 정지 6,852 → 108 ms (`verification/performance_results.md`)
- 난이도 차이: 대전 10경기 보통 7:3 쉬움, 어려움 8:2 보통, 어려움 8:2 쉬움
